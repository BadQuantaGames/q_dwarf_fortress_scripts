# q_dwarf_fortress_scripts

A collection of scripts for DFHack/Dwarf Fortress I use to automate/import large repeatitive tasks.

root\
    \blueprints		- Blueprints for 'gui/quickfort'
    \orders		- Work Orders to import via 'orders import <scriptname>'
    \stockpiles		- Import/Export stockpile settings for common ones


Mods I use that are needed for some of work orders:
